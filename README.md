# Перенос часов

Переносит часы из нарядов цехов в расшифровку ЗП, сверяясь с планом производства.

## Скачать

**[⬇ Скачать установщик для Windows](https://github.com/Teyrro/excel_process_hours_transfer/releases/latest/download/HoursTransfer-Setup.exe)**

Ссылка всегда ведёт на последнюю версию.

## Установка

1. Запустите скачанный `HoursTransfer-Setup.exe`. Права администратора не нужны.
2. Если Windows покажет «Система Windows защитила ваш компьютер», нажмите **Подробнее → Выполнить в любом случае** — установщик не подписан сертификатом, это нормально.
3. После установки программа открывается ярлыком **«Перенос часов»** на рабочем столе или в меню «Пуск».

Новая версия ставится тем же способом поверх старой.

## Как пользоваться

1. Добавьте файлы: наряды цехов (можно несколько, месяц — в названии), план производства и расшифровку ЗП. Нажмите «Выбрать» у нужного поля или перетащите файлы в окно.
2. Нажмите «Перенести часы».
3. Сохраните готовую расшифровку ЗП кнопкой «Сохранить». Исходные файлы не меняются.

## Удаление

Любой из способов:

- **Пуск → «Удалить «Перенос часов»»**;
- **Параметры → Приложения → Установленные приложения → «Перенос часов» → Удалить**.

Программа удаляется полностью, вместе с ярлыками.

## Для разработчика

Запуск из исходников:

```bash
pip install -r requirements.txt
python main.py
```

Выпуск новой версии: поставьте тег — GitHub Actions соберёт установщик и опубликует его в Releases.

```bash
git tag v1.0.0
git push origin v1.0.0
```

Сборка описана в [.github/workflows/release.yml](.github/workflows/release.yml), установщик — в [installer.iss](installer.iss).
